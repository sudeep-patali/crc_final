// 01 · Overview

About this project

What it does

CRC-ID takes a whole slide image (WSI), tiles it into thousands of tissue patches, filters out background, and runs every tissue patch through a two-stage model: first a binary triage (Normal vs. Tumor), then — for tumor patches only — an invasion-stage classifier. Results are aggregated into a single slide-level report: tumor fraction, per-stage distribution, deepest invasion reached, and a recommendation.

Objectives

  • Collect and preprocess histopathology data with Macenko stain normalization, resizing, pixel normalization, augmentation, and leakage-aware dataset splitting.
  • Design and implement a custom hybrid deep learning model for colorectal cancer identification and invasion-oriented stage classification.

Data sources

STAC-9 — pre-cut, labeled tissue patches (Normal / Tumor, and four invasion-related tissue types) used to train and evaluate both models.

TCGA-COAD & TCGA-READ — real whole slide images, used only for end-to-end pipeline validation on independent, unlabeled slides.

Scope & clinical framing

"Stages" here are a tissue-type proxy for invasion depth (mucosa → submucosa/stroma → muscularis → serosa/fat) — not full AJCC/pTNM clinical staging, which also depends on nodal and metastatic status not visible in a tissue patch. When the model isn't confident, it reports "unidentified" rather than guessing, and the slide-level logic flags "and beyond" when enough tissue was low-confidence that true invasion depth may exceed the reported stage.

// 02 · System design

How the model works

1. End-to-end slide pipeline

Every whole slide image goes through the same four stages before a result is shown.

2. Custom hybrid CNN–Transformer (used for both models)

The binary model and the stage model share the same architecture — only the final classification head differs (2 classes vs. 4 classes).

3. Preprocessing pipeline

  1. Macenko stain normalization
  2. Resize + pixel normalization
  3. Augmentation (flips, rotation, elastic, color jitter)
  4. Slide/patient-grouped 60/15/25 split
  5. Optuna hyperparameter tuning
